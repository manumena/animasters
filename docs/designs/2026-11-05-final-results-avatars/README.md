# Final results avatars

November 5, 2026. The owner asked for sketches that give avatars a role in the final results screen.

- **Winner spotlight** gives the winner a large portrait and keeps the complete scoreboard beside it.
- **Three-place podium** features the top three finishers and keeps the complete scoreboard visible.
- **Portrait cards** gives everyone a larger avatar and combines rank, score, and readiness in one grid.

All three use the same roster and retain the rematch action. The design controls allow a shared first place and a different featured portrait size. Tied players receive the same rank. The sample includes a player whose avatar falls back to an initial. The embedded portraits come from the lobby thumbnail sketch.

Open `preview.html` in a browser to compare the layouts. The owner selected Three-place podium alongside the full scoreboard. The implementation includes everyone tied for a podium place.
