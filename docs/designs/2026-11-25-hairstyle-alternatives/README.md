# Hairstyle alternatives

November 25, 2026. The owner requested new hairstyle alternatives to review after expanding the prop set.

The concept sheet compares six new silhouettes: Curtains, Swept undercut, Rounded curls, High ponytail, Twin tails, and Long layers. Each uses the same charcoal color and friendly face to make the shapes easier to compare. The existing bald avatar and spiky/bob hair assets were supplied as material and proportion references to the built-in image generation tool.

Open `preview.html` to review the full sheet. `source.html` is its editable HTML source. `assets/hairstyle-review-sheet.png` preserves the generated artwork; `generation.json` records the exact prompt and references.

The owner approved all six concepts. Individual transparent hair assets and a manual size/position editor are saved in the companion `2026-11-25-hairstyle-fit-editor` folder. The concept sheet remains here as the original reference; it is not a production sprite atlas. All six were calibrated and added to the app on November 25, including Long layers with separate rear and foreground hair regions.
