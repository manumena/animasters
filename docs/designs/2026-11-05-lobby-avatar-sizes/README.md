# Lobby avatar thumbnail sizes

November 5, 2026. The owner asked to compare thumbnail sizes in the room’s player list.

- **Current · 34 px** matches the current room roster.
- **Compact · 44 px** makes the face and prop easier to distinguish in a compact row.
- **Clear · 56 px** makes expressions and small accessories more legible.
- **Portrait · 72 px** gives the artwork the most space and makes the roster taller.

Each variant uses the same four sample players, circle crop, row padding, and ready states. The three soft 3D samples use the existing avatar artwork and saved prop contours. Sora shows the initials fallback. The art is embedded in the editable `source.html`. Open `preview.html` in a browser to switch sizes. The owner selected Clear (56 px) for the lobby’s player list.
