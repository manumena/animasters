# Podium avatar sizes

November 5, 2026. The owner asked to compare three portrait sizes on the chosen podium.

| Variant | First place | Second and third |
| --- | ---: | ---: |
| Current | 84 px | 68 px |
| Larger | 104 px | 84 px |
| Largest | 124 px | 104 px |

Each diameter is a maximum. A portrait scales down when its column is narrower. The variants use the same roster, crop, podium steps, and 34 px portraits in the full scoreboard. The editable `source.html` embeds the existing soft 3D sample portraits. Open `preview.html` in a browser to switch sizes. The owner selected Largest. The app caps first place at 124 px and second and third at 104 px, with the winner’s portrait staying larger as the columns narrow.
